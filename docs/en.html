AI Agent CLI System

Open-source platform managing AI Agents, Workflow Builder, Teams 3D Studio, Story Engine and Browser Automation. Automate tasks with a real-time web interface.

🚀 Get Started 📖 Architecture
ARCHITECTURE

10 Sub-Systems

TubeCLI is built from 10 subsystems working together

🤖

Agent Manager

Create and manage AI agents with persona, routine, skills, and cloud API keys. JSON storage, CRUD via CLI or API.

⚡

Skill System

Skills = ready-made workflow templates. 4 default skills. Agents are assigned skills to perform tasks.

🔄

Workflow Engine

DAG executor using Kahn's algorithm (topological sort). Nodes connect via ports, supports loop iteration.

🌐

API Server

FastAPI REST server with Swagger docs. CRUD endpoints for agents, skills, workflows. Auto-gen API documentation.

🔌

Extension System

Extensible architecture: Browser, Web Dashboard, Marketplace. Enable/disable via CLI, auto-inject commands and API routes.

🌐

Browser Engine

Manage browser profiles, proxy, fingerprint, cookies. Auto-login Google with TOTP 2FA. AI automation via prompts. Profile settings with proxy, OS/device fingerprint, Google Account.

🎨

Web Dashboard

SPA web interface at localhost:5295/dashboard. Manage agents, browser profiles (with profile settings ⚙️), workflows, skills, marketplace and settings. Auto-polling browser status in realtime.

👥

Teams Agents

Multi-agent orchestration: create team from template, hierarchical org chart, auto-delegate tasks to multiple agents by strategy (sequential, parallel, hierarchical).

🏢

3D Studio

Isometric 3D office (Three.js) with Roblox-style characters. 15+ asset types (desks, chairs, lights...). Per-team scene management. Fullscreen mode.

🎬

Story Engine

3D storytelling with a Script Editor that auto-generates dialogue. Play scripts visually via 3D Story Player with Speech Bubbles.

📖

AI Documentation (.agents)

SKILL.md documentation for External AI (Gemini, GPT) to understand the architecture and self-operate, write extension plugins without human intervention.

NODE TYPES

7 Node Types

Each node has typed ports (inputs/outputs) connecting into a workflow DAG

📝 Text Input text_input
Provides static text as input for the workflow.
Outputs: content, lines
🔄 Loop loop
Iterates over a list of items, executes downstream each iteration.
In: items → Out: current_item, index
🐍 Python Code python_code
Run arbitrary Python code. Access inputs via variables.
In: text_input, json_input → Out: result
🌐 API Request api_request
HTTP requests (GET/POST/PUT/DELETE) to APIs.
In: url, body → Out: response, status_code
💻 Run Command run_command
Run shell commands, capture stdout and exit code.
In: command → Out: stdout, exit_code
🧠 AI Inference ai_node
Call AI model (Ollama local or Cloud API).
In: prompt, context → Out: response
📤 Output output
Display or save the final result to a file.
In: data → Out: file_path

Instance: browser-a1b2c3d4
[AutoLogin] Login action completed.

# Xem status & dừng browser
❯ tubecli browser status
❯ tubecli browser stop "my-profile"
⏹ Browser 'my-profile' stopped.

# ═══ Profile Settings (⚙️ on Dashboard) ═══
# Each profile can be configured with:
• Proxy: socks5://user:pass@host:port
• Fingerprint: OS (Windows/macOS) + Browser
• Google Account: email|password|recovery|2fa_secret

# Auto-Login Flow when opening browser:
1. 1. Read google_account from profile config
2. 2. Check if logged in (myaccount.google.com)
3. 3. If not → auto enter email/password
4. 2FA → gọi API /api/v1/browser/2fa (TOTP live code)
5. 5. Login complete → continue original command

Team Builder

3D STUDIO

3D Office Visualization

Isometric 3D office with Roblox-style characters — visualize AI teams

🏢

Isometric 3D Office

Three.js renders a 3D workspace with floors, walls, lighting. Each team has its own theme (Dev, Marketing...). Orbit controls camera rotation.

🎮

Roblox-style Characters

AI agent characters displayed as 3D blocky figures (round head, box body). Each agent has a name label, hover tooltip, and float animation.

Procedural Assets & Raycasting

15+ furniture groups created with Procedural Composite Geometry (desks, chairs, rock gardens...). Group Raycasting supports click-select and drag-drop of entire groups.

💾

Scene Management

Save/load room layout per team. Customize room size, floor/wall colors. Scene CRUD API. Fullscreen mode (ESC to exit).
