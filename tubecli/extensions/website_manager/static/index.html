Cloudflare Credentials

Lưu API Token và Account ID để tái sử dụng khi deploy website. Dữ liệu lưu trong Cloud Keys.

➕ Thêm / Cập nhật Profile
API Token: My Profile → API Tokens → Create Token. Global API Key: My Profile → API Tokens → Global API Key (cần điền Email bên dưới)
Có email → xác thực kiểu Global API Key (X-Auth-Email + X-Auth-Key). Để trống → API Token (Bearer).
Cloudflare Dashboard → Trang chủ → sidebar phải
